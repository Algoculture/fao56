# Contributing

Please include tests for changes to calculation behavior and run `npm test`
before submitting a contribution. Cite scientific sources for changes to
equations, data, or guidance, and preserve source metadata and published ranges.

## Licensing contributions

By submitting a contribution, you agree that your original code and
documentation contributions are licensed under this project's MIT license.
Contributors retain copyright in their contributions; no copyright transfer
is required. The collective copyright notice is “Algoculture contributors”.

Third-party material must retain its applicable license and attribution.
FAO-derived data remain subject to CC BY 4.0 as described in
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md), rather than being relicensed
under MIT. Identify the source, license, and any adaptations when adding or
changing third-party material.
